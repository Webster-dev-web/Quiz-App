## What this app does
This is a "Life Hack or Myth?" quiz app. It tests your knowledge by showing you common statements (like "Drinking coffee helps you sleep better") and asking you to decide if each one is a real life hack (true) or just an urban myth (false). After you answer all 5 questions, it shows your score and a review of each answer with explanations.

## Features
- Start Sreen
- 5 Quiz Questions 
- Hack(True)/Myth(False) ButtoButtons 

## How to run
Open in Android Studio and click Run
